========================================================
VERSI STYLIZE "NAGAI-FY" (menu_screen/tools_card_art/*.jpg)
========================================================
20 file di tools_card_art/ diolah pakai script make_tool_art.py
(PIL + OpenCV): bilateral smoothing, posterisasi 28 warna, tint
shadow navy / highlight peach ala Hiroshi Nagai, SATURASI 2.0,
grain tipis. Bake 800x1280 (5:8 portrait, mendekati rasio frame
kartu biar minim overzoom).

Sumber per file (menu_screen/lab_*.jpg):
  - 13 file = foto internet (daftar di atas)
  - 7 file diganti art pilihan user (2026-10-27): complex
    (bidang kompleks), modmath (cover buku Real-World
    Cryptography), stats (permukaan gaussian 3D), taylor
    (poster Taylor series), thermo (roket Saturn V), matrix
    (diagram Minkowski), qm (permukaan potensial V(x)).
Kalau mau re-tune gaya: edit parameter di make_tool_art.py lalu
jalankan ulang. Ada file referensi video igexport-*.mp4 di
folder tools_card_art — bukan dipakai web, cuma referensi user.
